# 焊盘质心与容差边界对照

在项目根目录运行以下两行。参考值由 Python 标准库以 50 位十进制精度计算，生产核验仍使用 MoonBit。

```sh
moon build --target js
python tests/pad-centroid-oracle.py
```

脚本生成 Gerber、坐标表和配置，并从 CLI 报告读取 D1 的 `pad_evidence`。两张表使用相同坐标和基准，便于单独检查铜层核验。

| 算例 | 参考质心的求法 | 偏差档位 |
| --- | --- | --- |
| 两个矩形焊盘 | 面积为 1 和 3 mm²，按面积加权得到中心 | 低于、等于、高于 |
| 偏心圆宏 | 用整数系数计算镜像、90° 旋转、两倍缩放 | 低于、等于、高于 |
| 偏心双孔宏 | 从矩形面积和一阶矩扣除两个不同半径的圆孔，再应用变换 | 低于、高于 |
| 双孔宏拼板 | 选第 2 行第 2 列，还原到第一单元后使用同一解析质心 | 低于、高于 |

容差设为 0.25 mm，两侧用例各距限值约 0.000001 mm。精确等于限值时通过，高于限值时报告 `pad_offset`。双孔质心不能用有限位十进制精确写入这组坐标表，因此双孔用例只测试限值两侧。脚本还核对拼板编号、焊盘数和超限向量，并要求固定算例的计算距离与参考值相差不超过 0.000000001 mm。

结果保存在 `_build/pad-boundary/results.json`，Windows 和 Linux CI 都会复跑。表中误差要求适用于这些已知解析参考的验收用例。[对照脚本](../tests/pad-centroid-oracle.py)
