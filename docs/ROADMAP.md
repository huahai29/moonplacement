# Gerber 兼容路线

MoonPlacement 的重点是用 Gerber 铜层复查贴装坐标。开发顺序按对焊盘归属和质心判断的影响安排。目标固定为 Gerber Layer Format 2024.05，当前完成项和拒收边界见[规范命令矩阵](gerber-acceptance.md#规范命令矩阵)。[Ucamco 2024.05 规范](https://www.ucamco.com/files/downloads/file_en/456/gerber-layer-format-specification-revision-2024-05_en.pdf)

| 顺序 | 要补的语义 | 完成标准 |
| --- | --- | --- |
| 1. 光圈宏合成 | 扩展 `AM` 的多图元叠加、相交及跨边清除。组合仍须遵循宏内绘制顺序及曝光规则。 | 为合法多图元宏提供可运行输入，覆盖外部镜像、旋转和缩放。用解析几何对照面积与质心，用独立 Gerber 渲染器比对边界内外的铜点。保留非法轮廓的拒收用例。 |
| 2. X2 属性归属 | 0.3.0 已补齐属性保留、按名删除、块光圈来源与 SR 单元归属。继续核对标准属性值语法与复杂组合。 | [X2 回归](../gerber_attributes_wbtest.mbt)覆盖属性作用域和 SR 两条展开路径。后续对照使用具名属性的公开实板导出，确认复杂组合的作用域与复查行为。 |
| 3. 铜层清除与弧边界 | 补齐 `LP` 清除和回填对焊盘剩余铜形的影响，缩小 `D01`、`G02/G03`、`G36/G37` 弧段近似的边界。 | 提供清除穿过焊盘、仅相切、清除后回填三类可运行输入。每例都给出受影响位号、预期面积和质心或复查条件，检查远处焊盘结论不受影响。 |
| 4. 规范收尾 | 逐项复核命令矩阵中其余限制和合法命令的组合。 | 使用来源明确的公开合法文件，记录导出工具版本、参考实现、数值阈值和未通过项。完成规范 §2.12 的读取器复核后，才在发布说明里声明完整支持。 |

实板导出中的异常语法单独记录。以 Antmicro 原始顶铜 `FreePoly0` 的重复闭合点为例，当前报告会指出拒收原因，并保留底铜证据。即使后续增加兼容选项，也需保留严格模式的诊断和回归。[实板记录](cross-eda.md#用原始底铜核对-j1-与-c17)
